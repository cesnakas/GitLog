# Security Policy

## Supported Versions

Security updates are provided for the latest release of Git Log.

| Version | Supported |
| --- | --- |
| Latest release | ✅ |
| Older versions | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in Git Log, please do not report it through a public GitHub issue.

Use GitHub's **Private vulnerability reporting** feature to report security vulnerabilities privately.

Please include, where possible:

- a description of the vulnerability;
- steps to reproduce the issue;
- the affected Git Log version;
- the affected editor and version (Cursor or VS Code);
- any relevant logs, screenshots, or proof of concept.

Security reports will be reviewed as soon as possible.

Please avoid publicly disclosing the vulnerability until it has been investigated and, when necessary, a fix has been released.
